# 현재 화면 기준 개선안

아래 내용은 현재 모바일 캡처 화면을 기준으로 정리한 실무용 개선안이다.

## 1. 현재 화면에서 좋은 점

* 전체 톤이 밝고 부드러워져 기존보다 타깃 감성에 가까워졌다
* 메인 CTA가 중앙에 있고 구조가 단순해서 사용 흐름은 이해하기 쉽다
* “나도 할 수 있다” 메시지가 앱의 톤을 정하는 역할을 한다

## 2. 현재 화면의 핵심 문제

### 2-1. 상단 메시지 영역이 너무 크다

현재는 `LIVE SESSION` 배지 + 응원 카드가 타이머보다 위에 넓게 자리 잡고 있다.
모바일 1화면에서 가장 중요한 정보는 시간과 시작 버튼인데, 현재는 감성 요소가 기능 요소보다 먼저 눈에 들어온다.

### 2-2. 타이머 원형과 상태 정보의 위계가 약하다

원형 타이머는 크지만 상태 텍스트인 `준비 완료`, `라운드`, 음성 안내 문구가 전체적으로 연하고 작아서 집중 포인트가 분산된다.
“운동 시작 전 대기 화면”인지 “진행 중 화면”인지 한눈에 덜 들어온다.

### 2-3. 하단 컨트롤 존재감이 약하다

재생 버튼은 좋지만 좌우 보조 버튼과 점 표시, 상태 라인이 모두 엷고 비슷한 톤이라 눌러야 할 중심이 충분히 강하지 않다.
특히 `음성 안내가 여기 표시됩니다`와 `시작 버튼을 눌러...`가 placeholder처럼 보여 실제 앱의 생동감이 약하다.

### 2-4. “감성”은 생겼지만 “보상감”은 아직 약하다

현재 문구는 예쁘지만 사용자에게 즉각적인 정서 보상을 주는 표현은 약하다.
여성 타깃 웰니스 루틴 앱 느낌으로 가려면 “예쁜 화면”만으로는 부족하고, 짧고 다정한 피드백이 계속 보여야 한다.

## 3. 우선순위 높은 개선 방향

### 3-1. 메인 화면은 기능 우선, 감성은 보조로

모바일 타이머 화면에서는 정보 우선순위를 아래처럼 다시 잡는 것이 좋다.

1. 남은 시간
2. 현재 상태(준비/운동/휴식)
3. 시작 버튼
4. 짧은 감정 메시지
5. 보조 정보(라운드, 음성 안내, 점 표시)

즉, 감성 카드는 유지하되 크기를 줄이고 타이머를 더 위로 올려야 한다.

### 3-2. 응원 메시지는 “짧고 강하게” 바꾸기

현재 `나도 할 수 있다`는 방향은 좋지만 조금 더 현재성 있고 자기보상형으로 바꾸는 편이 낫다.

추천 문구:

* 오늘도 해낸 나, 꽤 멋진데?
* 지금은 나를 위한 20초
* 천천히, 하지만 분명하게
* 오늘도 루틴 성공 예약

메시지는 긴 문장보다 `한 줄 타이틀 + 짧은 보조 문장` 구조가 좋다.

### 3-3. 타이머 자체에 감정 표현 넣기

감정 요소를 카드에만 넣지 말고 타이머에 넣어야 한다.

추천:

* 준비 상태: 크림 옐로우 glow
* 운동 상태: 코랄 핑크 glow
* 휴식 상태: 민트/라일락 glow
* 3초 전: 링이 살짝 호흡하듯 커졌다 작아지기

이렇게 해야 “예쁜 화면”이 아니라 “살아있는 메인 화면”이 된다.

## 4. 화면 구성 개선안

### A안. 모바일 메인 타이머 최적안

상단에서 하단 순서:

* 작은 캡슐형 상태 배지
* 짧은 응원 문구 1줄
* 원형 타이머
* 라운드 정보
* 음성 안내 바
* 재생 버튼 중심 컨트롤
* 점 표시 + 아주 짧은 상태 문장

핵심은 현재보다 세로 여백을 줄이고, 응원 카드 높이를 절반 수준으로 줄이는 것이다.

### B안. 큰 화면 전용 설명 패널 유지안

사용자 요청대로 큰 화면에서는 설명 패널을 유지해도 된다.
다만 지금처럼 타이머와 거의 같은 존재감으로 두기보다 다음 원칙이 필요하다.

* 설명 패널은 좌측 30~35%
* 타이머 패널은 우측 65~70%
* 설명 패널은 더 흐리고 조용한 톤
* 타이머 패널이 시선의 중심이 되도록 대비 강화

즉, 큰 화면에서도 “설명”이 아니라 “메인 타이머”가 주인공이어야 한다.

## 5. 비주얼 디테일 제안

### 컬러

현재 핑크 단색 인상이 조금 강하므로 아래처럼 역할을 나누는 것이 좋다.

* 배경: 크림 화이트 + 베이비 핑크 + 아주 옅은 라일락
* 운동 강조: 코랄 핑크
* 휴식 강조: 민트
* 준비 강조: 바닐라 옐로우
* 텍스트: 회보라/모브 계열

### 버튼

* 메인 시작 버튼은 지금보다 약간 더 볼륨감 있게
* 보조 버튼은 더 작고, 반투명 + 미세한 그림자
* 눌렀을 때 살짝 말랑하게 들어가는 느낌

### 카드

* 현재 카드 테두리가 조금 많아 보일 수 있음
* 카드 수를 줄이고, 대신 배경 glow와 blur로 깊이감 표현

### 점 표시

* 단순 점 대신 현재 라운드만 말랑하게 커지는 애니메이션
* 완료된 점은 채워진 젤리 느낌

## 6. UX 문구 개선안

현재 문구를 아래처럼 더 감정형으로 바꾸는 안을 추천한다.

### 준비 상태

* 준비 완료
* 시작할 준비 됐어요
* 오늘도 내 리듬으로

### 운동 상태

* 운동 중
* 지금 나를 위한 시간
* 좋아, 아주 잘하고 있어

### 휴식 상태

* 잠깐 숨 고르기
* 잘하고 있어, 조금만 쉬어요
* 다음 세트도 충분히 할 수 있어요

### 완료 상태

* 오늘도 해냈어요
* 정말 잘했어요
* 내일의 나도 분명 좋아할 거예요

## 7. 바로 적용 추천

이번 화면에서 효과 대비 비용이 가장 좋은 순서는 아래다.

1. 모바일에서 응원 카드 높이 축소
2. 타이머와 상태 텍스트 대비 강화
3. 음성 안내 placeholder 문구를 실제 코칭형 문구로 교체
4. 운동/휴식/준비 상태별 glow 차별화
5. 완료 화면에 자기칭찬형 보상 문구 추가

## 8. 결론

현재 디자인은 방향 자체는 맞다.
문제는 감성 요소가 메인 기능보다 조금 앞에 나와 있다는 점이다.

다음 단계는 “더 꾸미기”가 아니라 아래 3가지를 맞추는 것이다.

* 모바일에서는 타이머가 가장 먼저 보여야 한다
* 감성 문구는 짧고 보상적으로 바뀌어야 한다
* 운동/휴식/완료 상태마다 화면 감정이 달라져야 한다
